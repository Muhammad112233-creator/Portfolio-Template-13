# The Long Way Home — interactive portfolio template

A small portfolio hidden inside a block-built house. Take the path from the front gate to the upstairs window, click the lit frames for project notes, or use the map if you already know where you are going.

This is an original, editable reimagining of the reference experience—not a copy of its source code, photographs, 3D models, or written portfolio content. The reference lists React, Three.js, and Blender; this version keeps the React + Three.js approach and builds its house and picture art procedurally in the browser, so there are no large model downloads to manage.

## What is here

- A full-screen, scroll-driven 3D walk-through with eight stops.
- Fast travel with lower- and upper-floor maps.
- Clickable, softly glowing project frames and case-note windows.
- Road-map, material-credit, keyboard-help, home, sound, and touch controls.
- Keyboard navigation: **A / D** or **← / →** to skip between stops; **F** for the map; **C** for credits; **R** for the road map; **M** for ambience; **Esc** to close.
- A small opt-in, synthesized night ambience. No audio starts until the visitor enables it.
- Responsive layout, reduced-motion styling, and a GitHub Pages workflow.

## Tech stack

- React 19 + Vite 8
- Three.js 0.186 via React Three Fiber 9
- Hand-placed procedural meshes, Canvas-drawn art, and CSS (no external photo/CDN dependencies)

## Preview it on your computer

You need Node.js 20.19 or newer and npm.

1. Open a terminal in this project folder.
2. Install the packages: `npm install` (or `npm ci` after the included lockfile exists).
3. Start the local preview: `npm run dev`.
4. Open the local URL printed by Vite—usually `http://localhost:5173/`.
5. To check the production build, run `npm run build`, then `npm run preview` and open the URL it prints.

On Arena, the live preview for the running **Website** process is also available in the preview pane. See `REFERENCE_STUDY.md` for the design breakdown, and `GITHUB_PUBLISH_GUIDE.md` for no-terminal GitHub upload steps and the GitHub Pages preview URL.

## Make it yours

Start in [`src/content/portfolio.js`](src/content/portfolio.js). Replace the demo name, intro, email, socials, project summaries, and room notes. The visible sample person, Mira Chen, is fictional placeholder copy; do not publish it as your own bio.

Also update:

- `index.html` — page title, description, and social-preview metadata.
- `vite.config.js` — change `githubPagesBase` if you choose a different GitHub repository name.
- `public/favicon.svg` — replace the small house mark if you have your own identity.

The three project picture frames are drawn from the `palette` and `motif` values in `portfolio.js`. The available motifs are `sunrise`, `clouds`, and `atlas`; add another branch in `Artwork` in `src/components/World.jsx` if you want a new scene illustration.
